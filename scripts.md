# Скрипты «Лектория»

Текущий pipeline находится в `03_app/scripts`.

Общий прогресс лекций хранится в корневом файле `lectures.md`. Скрипты 01–07
обновляют в нём статус и список успешно пройденных этапов. Скрипт 07 переводит
лекцию в статус `Готово`.

## 0. `00_run_pipeline`

Проверяет окружение и запускает шаги 01–06 по порядку. 07-й этап запускается
отдельно для всех лекций, у которых появилась пара JSON + summary.

```powershell
python 03_app/scripts/00_run_pipeline.py "01_lectures\0-0_Тесты\2026-09-09_19-15"
```

Для предварительной проверки используйте `--dry-run`, для перезаписи метаданных — `--force-meta`.

## 1. `01_create_lecture_meta`

Создаёт `_meta.yaml` в корне папки лекции.

## 2. `02_bind_video_screenshots`

Связывает видео и скриншоты по времени, выполняет OCR скриншотов и переносит файлы в `source/` и `source/fragments/`. Папка `source/fragments/` создаётся только при наличии скриншотов.

## 3. `03_extract_audio`

Создаёт WAV-файлы из видео и аудио в `source/`. Имя формируется по шаблону `<семестр>-<предмет>_<дата>_<время>.wav`.

## 4. `04_transcribe_turbo`

Транскрибирует WAV через локальный Whisper `large-v3-turbo` и сохраняет результат в `json/transcript.json`.

## 5. `05_extract_pdf`

Обрабатывает PDF только через OCR, переносит презентации в `source/` с именем `<семестр>-<предмет>_<дата>_<время>.pdf` и сохраняет результат в `json/pdf.json`.

## 6. `06_merge_lecture_data`

Объединяет исходную транскрипцию, метаданные, тайминги и OCR скриншотов, а также PDF в `json/<lecture_id>.json`.

## 7. `07_render_markdown`

Сканирует весь `01_lectures` и для каждой папки, где в `json/` есть пара
`<имя>.json` и `<имя>_summary.json`, создаёт Markdown по шаблону
`lecture.md.j2`. Основной JSON и summary должны иметь одинаковое базовое имя.

```powershell
python 03_app/scripts/07_render_markdown.py
```

Для одной папки используйте путь лекции, для предварительной проверки —
`--dry-run`. Уже созданные Markdown пропускаются; для их перегенерации используйте
`--force`.

## 8. `08_publish_vault`

Сканирует весь `01_lectures`, находит только лекционные Markdown с YAML-полями
`title`, `summary`, `date` и `subject`, копирует их в `02_vault`, переносит
используемые изображения, обновляет индекс и файлы Jekyll.

```powershell
python 03_app/scripts/08_publish_vault.py
```

## 9. `09_publish_github`

Сначала запускает общий экспорт `08_publish_vault`, затем добавляет `02_vault`
и workflow GitHub Pages в коммит. По умолчанию сообщение формируется по
локальной дате и времени, а коммит автоматически отправляется в GitHub.

```powershell
python 03_app/scripts/09_publish_github.py
```

Для коммита без push используйте `--no-push`, для собственного сообщения —
`--message`, для коммита без повторного экспорта — `--skip-export`.

## 10. `10_transcribe_folder`

Последовательно транскрибирует все аудио- и видеофайлы выбранной папки, не меняя исходники и не запуская другие этапы.

```powershell
python 03_app/scripts/10_transcribe_folder.py "C:\Users\Timur\Desktop\Folder"
```

По умолчанию JSON сохраняются в `transcripts/` внутри исходной папки. Для проверки списка файлов без запуска используйте `--dry-run`; для повторной транскрибации готовых файлов — `--force`.
