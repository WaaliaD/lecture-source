# Лёгкий конвейер «Лектория»

Скрипты рассчитаны на папку одной лекции. `_meta.yaml` лежит в корне папки:

```text
лекция/
├─ _meta.yaml
├─ source/
│  └─ fragments/
├─ transcript/
└─ json/
```

Запускать из корня проекта:

```powershell
python 03_app/scripts/00_run_pipeline.py 01_lectures/1-1_Предмет/2026-09-14_10-00
```

Или запускать отдельные шаги:

```powershell
python 03_app/scripts/01_create_lecture_meta.py 01_lectures/1-1_Предмет/2026-09-14_10-00
python 03_app/scripts/02_bind_video_screenshots.py 01_lectures/1-1_Предмет/2026-09-14_10-00
python 03_app/scripts/03_extract_audio.py 01_lectures/1-1_Предмет/2026-09-14_10-00
python 03_app/scripts/04_transcribe_turbo.py 01_lectures/1-1_Предмет/2026-09-14_10-00
python 03_app/scripts/05_extract_pdf.py 01_lectures/1-1_Предмет/2026-09-14_10-00
python 03_app/scripts/06_merge_lecture_data.py 01_lectures/1-1_Предмет/2026-09-14_10-00
```

У общего запуска доступны `--dry-run` и `--force-meta`. Перед запуском выполняется проверка окружения;
при проблемах выводится список исправлений без traceback. При ошибке отдельного
шага pipeline также останавливается без traceback.

Перед шагом 02 видео и скриншоты находятся прямо в корне лекции. Скрипт
связывает их по датам и времени в именах, затем перемещает видео в `source/`,
а скриншоты — в `source/fragments/`. Видео и аудио уже в `source/` шаг 03
конвертирует в WAV с тем же базовым именем.

Скрипт транскрипции использует `large-v3-turbo`, VAD и словарь из
`<subject>/_context/vocabulary.txt` текущего предмета, если файл существует, как старый шаг 05. При отсутствии словаря Whisper запускается без подсказки. Сырые ответы Whisper
сохраняются непосредственно в `transcript/`, объединённый результат — в
`json/transcript.json`.

Для ASR по умолчанию используются бинарник и модели из `03_app/whisper`.
Скрипт PDF использует только OCR через `pdftoppm` и `tesseract`; текстовый
слой PDF намеренно не используется. Если PDF есть, оба инструмента обязательны.
Шаг 06 не использует LLM и не строит дополнительные связи: он сохраняет
исходную транскрипцию, тайминги и имена файлов скриншотов, OCR изображений и
содержимое `pdf.json` в одном итоговом JSON-файле `json/<lecture_id>.json`.
Шаг 07 использует только `*_summary.json` и не читает основной JSON лекции.
